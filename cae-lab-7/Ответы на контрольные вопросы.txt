Ответы на контрольные вопросы
Формирование векторов и матриц — прямой ввод через квадратные скобки ([1 2 3]), генерация встроенными функциями (zeros, ones, rand, eye, randn, diag), через двоеточие-диапазон (1:0.5:10), через функции linspace, reshape.
Матрица как вектор-столбец — вводится через точку с запятой между элементами: w = [1; 2; 3; 4] (в отличие от вектор-строки, где элементы разделяются пробелом или запятой).
Двоеточие при формировании векторов — задаёт диапазон значений с определённым шагом: начало:шаг:конец, например 0:0.1:1 — вектор от 0 до 1 с шагом 0.1; если шаг не указан, по умолчанию он равен 1.
Выделение блоков матриц — через индексацию диапазонами: m(1:2, 3:4) выделяет подматрицу из строк 1–2 и столбцов 3–4; символ : без чисел означает "все элементы" по этому измерению (m(:,2) — весь второй столбец).
Просмотр переменных рабочей среды — команда whos (с подробностями о размере и типе) или who (только имена), а также панель Workspace в графическом интерфейсе.
Размер матриц для сложения/вычитания — матрицы должны иметь одинаковую размерность (одинаковое число строк и столбцов), поэлементные операции применяются к соответствующим элементам.
Оператор перемножения матриц — * (обычное матричное умножение по правилам линейной алгебры, требующее совпадения внутренних размерностей); для поэлементного — .*.
Горизонтальная конкатенация — квадратные скобки с матрицами через запятую/пробел: [A, B] (требуется одинаковое число строк).
Вертикальная конкатенация — квадратные скобки с матрицами через точку с запятой: [A; B] (требуется одинаковое число столбцов).
Нулевая матрица — функция zeros(m,n).
Матрица от eye — единичная матрица (единицы на главной диагонали, нули вне её); eye(n) — квадратная

Нормальное распределение (среднее 0, дисперсия 1) — функция randn(m,n).
Функция fliplr — формирует матрицу, полученную зеркальным отражением исходной по горизонтали (переставляет столбцы в обратном порядке, "left-right flip").
Функция diag — при подаче вектора строит квадратную матрицу с этим вектором на главной диагонали (и нулями вне её); при подаче матрицы, наоборот, извлекает из неё вектор главной диагонали.
Функция ones — матрица, все элементы которой равны единице; ones(m,n) задаёт размер.
Функция reshape — изменяет форму (число строк и столбцов) массива без изменения общего числа и порядка его элементов (данные "перетекают" по столбцам в новую форму).
Транспонирование матриц — оператор апострофа ' (например, m'); для комплексных матриц ' даёт эрмитово-сопряжённую матрицу, а .' — обычное транспонирование без сопряжения.
Обратная матрица — функция inv(m) (для квадратной невырожденной матрицы); также можно решать системы через m\b без явного построения обратной матрицы (что предпочтительнее с точки зрения численной устойчивости).
Графические возможности MATLAB — двумерные графики (plot), трёхмерные (plot3, surf, mesh), гистограммы (bar, hist), полярные графики (polarplot), контурные графики (contour), сохранение и экспорт изображений, интерактивные аннотации, subplot для нескольких графиков в одном окне.
Стиль графика — через строковый параметр в plot(x,y,'стиль'), задающий одновременно цвет (например 'r'), тип маркера ('o', '*', 's') и тип линии ('-', '--', ':', '-.'), либо через именованные параметры ('Color', 'LineStyle', 'Marker', 'LineWidth').
Несколько функций на одном графике — последовательные вызовы plot с командой hold on между ними, либо один вызов plot(x1,y1,x2,y2,...) со всеми парами сразу.
Команда hold on — не даёт последующим командам plot очищать текущие оси, позволяя накладывать несколько графиков друг на друга в одном окне (hold off возвращает поведение по умолчанию).
Координатная сетка — команда grid on (отключается через grid off).
Логарифмический масштаб графика — функции semilogx (лог. шкала по X), semilogy (лог. шкала по Y), loglog (обе оси в лог. масштабе), либо set(gca, 'XScale', 'log') / 'YScale', 'log' для уже построенного графика.
Графики в полярной системе координат — функция polarplot(theta, rho) (в новых версиях MATLAB) или устаревшая polar(theta, rho).
Тип точки, цвет и тип линии — через строку стиля в plot (например 'ro--' — красные кружки-маркеры, соединённые штриховой линией) либо через отдельные именованные параметры ('Marker', 'Color', 'LineStyle').
Аргументы subplot(m,n,p) — m — число строк сетки подграфиков, n — число столбцов сетки, p — номер текущей ячейки (позиции), в которую будет помещён следующий график, нумерация идёт слева направо, сверху вниз.
Подписи осей координатной сетки — функции xlabel('текст'), ylabel('текст') (и zlabel для трёхмерных графиков); название всего графика — title('текст').
